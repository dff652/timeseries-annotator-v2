# 时序数据标注工具 v2 重构与优化进展汇报

## 一、 重构概述
本次重构完成了从“单文件上帝组件”向“模块化、受控交互”架构的转型。解决了代码难以维护、数据流混乱、图表性能瓶颈及持久化安全四大核心痛点。

## 二、 已完成任务清单 (Completed)

### 1. 后端架构 (Backend)
- **BA-01 路由蓝图化**: `app.py` 拆分为 `auth`, `data`, `annotation`, `label` 四个模块，提高了接口的可维护性。
- **BA-02 下采样优化**: 增强 M4 算法，支持通过 API 参数 `limit` 动态控制返回点数，显著提升大数据加载速度。
- **BA-03 原子持久化**: 引入临时文件写入机制，确保在保存标注时不会因系统崩溃或网络中断导致 JSON 文件损坏。
- **路径配置中心**: 统一通过 `config.py` 管理服务器存储路径。

### 2. 前端组件化 (Frontend)
- **FCD-01/02 布局解耦**: 提取了 `MainNavbar`, `LeftSidebar`, `RightSidebar`, `ChartArea`, `Modals` 等 10 余个子组件。
- **FCD-03 状态管理**: 建立了基于 `Vue.observable` 的轻量级 Store，统一管理用户、标签和全局 UI 状态。
- **逻辑剥离**: 创建了 `src/api/`, `src/utils/` (dataTransform, labelUtils) 等服务层，`Index.vue` 代码量缩减 80% 以上。

### 3. 可视化交互 (Visualization)
- **VE-01 D3 受控封装**: 成功将 D3 逻辑封装入 `TimeSeriesChart.vue`，实现数据驱动绘图。
- **VE-02 通讯机制升级**: 彻底废弃 Hack 式隐藏按钮，改为标准的 Props/Events 交互。
- **VE-03 交互同步**: 实现了单点点击、框选操作与 Vue 业务逻辑的实时状态同步。

### 4. 性能与 UX
- **压力测试基准**: 生成了 10 万点测试数据集，建立了性能评估脚本。
- **快捷键支持**: 实装了 `Ctrl+S` 快速保存功能。

## 三、 待完成/待加固任务 (Pending / Backlog)

1. **Undo/Redo 交互逻辑**: Store 层已留出占位符，但 UI 撤销/重做按钮及具体的历史栈逻辑尚未完全闭环。
2. **UI 细节调优**: 重构后组件间的 CSS 边界可能存在细微偏差，需在不同分辨率下进行最后的视觉校对。
3. **正式回归测试**: 尚未完成所有极端情况（如文件格式错误、Token 过期瞬间保存）的压力测试。
