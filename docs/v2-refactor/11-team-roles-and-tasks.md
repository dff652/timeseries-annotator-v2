# 时序数据标注工具 v2 开发分工与职责表

## 1. 角色定义与职责范围

### 🛠️ 后端架构师 (Backend Architect)
- **职责**: API 稳定性、数据处理性能、用户认证安全。
- **重点**: Blueprint 模块化改造、高性能下采样、JWT 权限校验、标注数据一致性。

### 🎨 前端组件开发者 (Frontend Component Dev)
- **职责**: UI 拆构、响应式状态管理、组件间通讯、UI/UX 细节。
- **重点**: `Index.vue` 瘦身、提取独立组件、建立 API Service 层、样式标准化。

### 📈 可视化专家 (Visualization Expert)
- **职责**: D3.js 核心渲染逻辑、交互性能、图表组件化。
- **重点**: `TimeSeriesChart.vue` 封装、废弃 Hack 式通讯、优化 Brush/Zoom 性能、同步缩略图逻辑。

### 📋 项目经理/QA (PM & QA)
- **职责**: 任务进度追踪、集成验证、文档同步、回归测试。
- **重点**: 验证重构后的功能闭环、维护 API 文档。

## 3. 协作流程与规范
1. **API 先行**: 后端修改接口前，必须先在 `docs/v2-refactor/08-data-schema-spec.md` 更新协议。
2. **状态受控**: 子组件不允许直接修改父组件传入的 Props，统一通过 `$emit` 请求父组件更新。
3. **工具函数化**: 所有的格式转换逻辑必须放在 `src/utils/` 下，严禁在组件生命周期内硬编码转换逻辑。
